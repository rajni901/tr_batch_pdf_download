How to Use

1

Go to any list view

Open Invoices, Sale Orders, Purchase Orders or Inventory Transfers list view.

2

Select records

Tick the checkboxes for the records you want to download. Select as many as needed.

3

Click Action → Download PDFs as ZIP

Click the Action button → select Download PDFs as ZIP → click Download ZIP in the popup.

4

ZIP downloads automatically

A ZIP file downloads to your computer containing all PDFs — ready to email, archive or print.
